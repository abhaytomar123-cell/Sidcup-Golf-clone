# Sidcup Family Golf - Website Clone

This is a frontend practice project inspired by the Sidcup Family Golf website. I am building this project to improve my skills in HTML, CSS, JavaScript, animations, and responsive web design.

## About the Project

The website is based on the design and interactions of Sidcup Family Golf.

The project includes:

* Navigation bar
* Hero section
* Video background
* Interactive sections
* Website animations
* Responsive layout
* Modern UI design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GSAP

## What I Learned

While building this project, I am practicing:

* Creating layouts using HTML and CSS
* CSS positioning and flexbox
* JavaScript interactions
* GSAP animations
* Working with video backgrounds
* DOM manipulation
* Structuring a frontend project
* Using Git and GitHub
